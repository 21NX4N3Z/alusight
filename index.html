01 · ปัญหา

รูพรุนในอะลูมิเนียมหล่อ

รูพรุน (Porosity) เป็นข้อบกพร่องที่เกิดขึ้นบ่อยที่สุดในชิ้นงานอะลูมิเนียมหล่อ เกิดจาก 2 สาเหตุหลัก คือ การละลายของก๊าซไฮโดรเจน (H₂) ในโลหะเหลว และ การหดตัวขณะเชื่อมตัวแข็ง (Shrinkage)

1
ลดความแข็งแรงรูพรุนเป็นจุดเริ่มต้นของรอยแตก ทำให้ชิ้นงานแข็งแรงน้อยลง
2
รั่วซึม / ลดความทนทานรูพรุนเชื่อมต่อกันเป็นช่องว่าง ทำให้ชิ้นงานรั่วซึมและสึกหรอเร็ว
3
ต้องเตรียม sample ล่วงหน้าการตรวจแบบดั้งเดิมต้องเฉือน/ขัดจนเป็น cross-section สูญเสียชิ้นงาน
4
ไม่สามารถสืบย้อนหลังได้ไม่มีบันทึกข้อมูลการเกิด defect เชิงปริมาณและพิกัด
🔬

กลไกการเกิดรูพรุน

ไฮโดรเจนละลายในอะลูมิเนียมเหลวสูงมาก (ประมาณ 20 เท่าของอะลูมิเนียมแข็ง) เมื่อเย็นตัว ก๊าซถูกปัดตัวออก เกิดเป็นฟองก๊าซในโซนเชื่อมตัวแข็งช้า (pasty zone) ประกอบกับการหดตัว ทำให้เกิดรูพรุนขนาดเล็กจำนวนมาก

ปัจจัยที่ส่งผล: อุณหภูมิหล่อ · อัตราคูลลิ่ง · การ degas · ปริมาณ H₂ · ส่วนผสม Si / Sr / Ti

03 · ระบบการทำงาน

5 ขั้นตอน จากภาพดิบ → ผลลัพธ์

1

นำเข้าภาพจุลทรรศน์ (OM)

ถ่ายภาพโครงสร้างจุลภาคของอะลูมิเนียมหล่อ พร้อมบันทึกพิกัด stage X,Y, magnification และ scale bar

2

วิเคราะห์ภาพ

ใช้ Gaussian blur + percentile threshold + morphological opening เพื่อแยกรูพรุนออกจาก matrix แล้วคำนวณ % porosity, จำนวนรู และขนาด

3

AI Detection

จำแนกและระบุตำแหน่งรูพรุน/อนุภาคด้วย unsupervised clustering + connected components พร้อม confidence score

4

Electrical Map (ECA)

สแกนชิ้นงานด้วย Eddy Current Array เพื่อได้สัญญาณ amplitude/phase บนกริด X,Y — ใช้ตรวจรอยแตก/รอยผิว (skin depth ~0.27 mm)

5

เทียบกัน + สืบย้อนหลัง

ผูกข้อมูลรูพรุนจาก OM เข้ากับสัญญาณ ECA ในสเปซพิกัดเดียวกัน แล้วเชื่อมกับ process parameters เพื่อปรับปรุงกระบวนการผลิต
